# AutoSub-Reels 🎬

AutoSub-Reels is a lightweight Python automation tool designed to extract audio from short-form videos (Reels, Shorts, TikToks) and generate highly accurate `.srt` subtitles using OpenAI's Whisper model. It is optimized out-of-the-box for RTL languages like Persian, making it ideal for educational and medical content creators.

## Features
- **Automated Extraction:** Seamlessly rips audio from video files using `FFmpeg`.
- **AI Transcription:** Leverages OpenAI's Whisper for state-of-the-art speech recognition.
- **RTL Support:** Default configurations tailored for Persian (fa) content creation.
- **CLI Interface:** Easy to use directly from your terminal.
